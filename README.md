
# EDA Project

## Overview

This is an Exploratory Data Analysis (EDA) project that leverages **Jupyter Lab** for interactive data exploration and **Power BI** for dynamic visualizations and business insights. This repository demonstrates a complete workflow from data loading and cleaning through advanced visualization and reporting.

## 📊 Project Features

- **Interactive Data Analysis** using PowerBI
- **Data Cleaning & Preprocessing** with Python libraries
- **Statistical Analysis** and descriptive statistics
- **Advanced Visualizations** using Python plotting libraries
- **Power BI Dashboard** for executive-level insights and KPI tracking
- **Reproducible Analysis** with well-documented code and notebooks

## 🛠️ Tech Stack

### Data Analysis & Processing
- **Jupyter Lab** - Interactive notebook environment for exploratory analysis
- **Python** - Primary programming language
- **Pandas** - Data manipulation and analysis
- **NumPy** - Numerical computing
- **matplotlib**-for visuals representation

### Data Visualization
- **Matplotlib** - Static visualization library
- **Power BI** - Business intelligence and dashboard creation
